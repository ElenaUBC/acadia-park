# Acadia Park Community Events

Event pages for Acadia Park residents, published with GitHub Pages at https://elenaubc.github.io/acadia-park/

- `index.html` – list of events
- `movie-night/` – Adult & Teen Movie Night: schedule, ratings and voting (votes go to a Google Form)
- `winter-gallery/` – Holiday Winter Gallery (December 22 and 23)

To add a new event, make a new folder with its own `index.html` and add a link to it on the main `index.html`.
